# Sample Python Project

This is a sample Python project for HarborPilot E2E testing.

## Description

A simple Python application that demonstrates basic functionality for testing HarborPilot workflows.

## Features

- Basic Python module structure
- Unit tests
- Documentation
- Configuration files

## Structure

```
sample_python_project/
├── src/
│   ├── __init__.py
│   ├── main.py
│   └── utils.py
├── tests/
│   ├── __init__.py
│   ├── test_main.py
│   └── test_utils.py
├── docs/
│   ├── requirements.md
│   └── api.md
├── requirements.txt
├── setup.py
└── README.md
```

## Usage

```bash
python src/main.py
```

## Testing

```bash
python -m pytest tests/
```
